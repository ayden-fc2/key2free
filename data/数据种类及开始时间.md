## 数据范围说明

### 股票数据

* 日、周、月K线数据，时间范围：1990-12-19至今。
* 5、15、30、60分钟K线数据，时间范围（近5年）：2019-01-02至今。

### ETF数据

* 日、周、月K线数据，时间范围：2026-01-05至今。
* 5、15、30、60分钟K线数据，时间范围：2026-01-05至今。

### 指数数据

* 日、周、月K线已经包含指数(不提供分钟K线数据)：综合指数，规模指数，一级行业指数，二级行业指数，策略指数，成长指数，价值指数，主题指数，基金指数，债券指数。
* 时间范围：2006-01-01至今。

### 季频财务数据

* 已经包含的财务数据：部分上市公司资产负债信息、上市公司现金流量信息、上市公司利润信息、上市公司杜邦指标信息。
* 时间范围：2007年至今。

### 季频公司报告

* 上市公司业绩预告信息，时间范围：2003年至今。
* 上市公司业绩快报信息，时间范围：2006年至今。

## 当前源数据表命名

项目内统一使用 `source` schema 承载从 BaoStock 同步来的原始数据，`mart` schema 承载二次计算后可直接用于策略的数据，`meta` schema 承载数据集目录、水位、任务和校验等元数据。

| 表名 | 说明 |
| --- | --- |
| `source.security_master` | 证券主表 |
| `source.trade_calendar` | 交易日历 |
| `source.all_stock_snapshot` | 全股票快照 |
| `source.bar_1d_raw` | 日线行情 |
| `source.bar_5m_raw` | 5分钟行情 |
| `source.adjust_factor` | 复权因子 |
| `source.dividend` | 分红数据 |
| `source.profit` | 利润表 |
| `source.operation` | 营运能力 |
| `source.growth` | 成长能力 |
| `source.balance` | 偿债能力 |
| `source.cash_flow` | 现金流量 |
| `source.dupont` | 杜邦指数 |
| `source.performance_express` | 业绩快报 |
| `source.forecast` | 业绩预告 |
| `source.deposit_rate` | 存款利率 |
| `source.loan_rate` | 贷款利率 |
