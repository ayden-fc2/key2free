# 小市值低价轮动策略

## 一、搭建安全基础池

每日用当日收盘后已知数据构建基础池：

1. 排除上市不足 250 天的次新股。
2. 排除科创板、创业板、北交所、ST、`*ST`：
   - 保留 `sh.6*`、`sz.0*`
   - 排除 `sh.688*`、`sz.300*`、`sz.301*`、`bj.*`
   - `is_st == 0`
   - 股票名称不包含 `ST`
3. 最近一个季度每股收益 `eps < 0` 的股票排除。

## 二、筛选低价

1. 使用宽表字段 `close`，即不复权收盘价。
2. 在基础池中按 `close` 从低到高排序。
3. 取全市场最低价 10% 股票作为低价池。

## 三、精选核心标的

在低价池中：

1. 使用 `daily_basic.circ_mv` 作为流通市值。
2. 按流通市值从小到大排序。
3. 选取前 10 只作为最新目标持仓池。

## 四、核心买卖规则

1. 每个交易日都计算目标池，但只在每周一开盘执行调仓。
2. 周一开盘使用上一交易日收盘后生成的目标池。
3. 当前持仓不在最新目标池中，按周一开盘价卖出。
4. 最新目标池中尚未持有的股票，按周一开盘价买入。
5. 目标持仓为 10 只，按总资产等权分配仓位。
6. 目标池内已有持仓也会在周一开盘尽量调回等权；超配则减仓，低配则补仓。

## 五、调仓风控

周一调仓买入时，下列股票不买：

1. 调仓日开盘已经涨停或跌停。
2. 上一交易日涨停或跌停。
3. 停牌、零成交量、无有效行情。
4. 一字板等流动性枯竭标的。

其中调仓日开盘涨跌停只使用开盘时可知信息判断：

```text
abs(open(D) / pre_close(D) - 1) >= 9.8%
```

上一交易日涨跌停使用上一交易日已知涨跌幅判断：

```text
abs(pct_chg(D-1)) >= 9.8%
```

## 六、灵魂规则：涨停不连板提前卖出

每天收盘检查持仓：

```text
pct_chg(D-1) >= 9.8%
pct_chg(D) < 9.8%
```

如果昨天涨停，但今天没有继续封住涨停，则今天收盘价卖出。该规则每天检查，不限于周一调仓日。

## 七、无未来函数约束

1. 目标池使用信号日收盘后已知数据生成。
2. 周一开盘调仓使用上一交易日目标池。
3. 开盘涨跌停过滤只使用调仓日开盘价和前收盘价。
4. 涨停不连板卖出是收盘规则，按当天收盘可观察状态执行。
