# 小市值低价轮动策略

本策略是新回测生命周期接口的规范样板。策略自己维护信号选择、卖出决策、买入决策和观望池更新；通用回测框架只负责执行订单、维护现金/持仓和记录结果。

## 1. 交易节奏

当前版本不启用中证500市场环境过滤、Top500 牛熊指标、指数 MA20、金叉死叉或 20 日低点过滤；保留交易周时钟和 7/7 日常卖出。

1. 每个交易周最后一个开市日 T 收盘后计算一次目标池信号。
2. 下一交易周第一个开市日开盘执行买入和调仓。
3. 交易周边界来自框架传入的 `context.params.trading_clock`，底层使用 `tushare.trade_cal`。周五遇节假日时，信号日自动提前到该交易周实际最后一个开市日；周一遇节假日时，调仓日自动顺延到该交易周实际第一个开市日。
4. `trading_clock` 同时包含本周期交易日、前后开市日窗口、周期起止、`period_day_index`、`period_day_count`、`is_period_start`、`is_period_end`；策略使用默认交易周节奏：周期末出信号，周期初调仓。
5. 非信号日不刷新观望池；非调仓日只执行日常卖出规则。

正式策略已移除压测探针参数：

1. 信号阶段只加载选股所需字段：`name`、`list_date`、`close`、`is_st`、`eps`、`circ_mv`。
2. `signal_history_window = 0`，只读取信号日 T 的横截面。
3. 信号载荷不再附带 `qfq_close`、`total_mv` 或买入历史探针。

## 2. 收盘后选信号

信号日 T 收盘后，策略读取截至 T 日的完整宽表横截面，生成最新目标池：

1. 排除上市不足 250 天的次新股。
2. 排除科创板、创业板、北交所、ST、`*ST`。
3. 最近一个季度 EPS 小于 0 的股票排除。
4. 使用不复权收盘价 `close`，筛选全市场最低价 10% 股票。
5. 在低价池内按 `circ_mv` 从小到大排序，选取指定排名区间作为目标池。

当前参数：

```text
target_holdings = 10
low_price_quantile = 10%
circ_mv_rank_start = 1
circ_mv_rank_end = 10
```

## 3. 卖出决策

回测系统在每日 T 交易阶段调用策略卖出函数。策略只使用 T 日可观察行情字段，不使用 T 日 MA、ATR 等收盘后宽表指标。

卖出规则：

1. 每天检查持仓，如果上一交易日涨幅不低于 7%，T 日收盘涨幅低于 7%，则按 T 日收盘价卖出。
2. 只在交易周第一个开市日执行周频调仓。
3. 调仓日开盘时，持仓不在最新目标池内则卖出。
4. 如果调仓日开盘涨停，则不因调仓卖出，继续持有。
5. 目标池内已有持仓会尽量调回等权，超配则在调仓日开盘减仓。

## 4. 买入决策

回测系统在每日卖出后调用策略买入函数。策略使用卖出后的现金池，乐观假设当日卖出资金可用于当日买入。

买入规则：

1. 只在交易周第一个开市日开盘执行买入。
2. 使用上一交易周最后一个开市日收盘后生成并保存在观望池中的目标池。
3. 目标持仓等权分配。
4. 调仓日开盘涨停或跌停的股票不买。
5. 上一交易日涨停或跌停的股票不买。
6. 停牌、零成交量、无有效行情、一字板等流动性枯竭标的不买。

## 5. 观望池更新

每个交易周最后一个开市日 T 收盘后，策略把当日最新目标池写入观望池。非信号日不刷新观望池。下一交易周第一个开市日开盘买入时实际使用的是 T 日收盘后已经确定的目标池。

## 6. 无未来函数约束

1. 选信号阶段模拟 T 收盘后，可以使用 T 日完整宽表。
2. 卖出和买入阶段只使用 T 日开盘、最高、最低、收盘、成交量、涨跌幅、前收盘等交易中可观察字段。
3. 卖出和买入阶段不得使用 T 日 MA、ATR、均量等收盘后宽表指标。
4. 周频调仓使用上一交易周最后一个开市日收盘后生成的目标池，不读取调仓日收盘后的选股结果。
5. 交易日历属于公开可预知信息，框架允许用 T 前后一段开市日排列定位交易周期开始/结束；这只影响时钟判断，不提供未来行情。
6. 当前策略不读取指数日线、指数每日指标或 T+1 之后的任何股票行情、财务数据、宽表指标。
