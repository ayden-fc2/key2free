# 小市值低价轮动策略

本策略是新回测生命周期接口的规范样板。策略自己维护信号选择、卖出决策、买入决策和观望池更新；通用回测框架只负责执行订单、维护现金/持仓和记录结果。

## 1. 交易节奏

策略按交易周运行，而不是按自然周固定星期几运行：

1. 每个交易周最后一个开市日收盘后计算信号。
2. 下一交易周第一个开市日开盘执行调仓。
3. 交易周边界来自 `tushare.trade_cal`。如果周五休市，则提前到本周最后一个开市日发信号；如果周一休市，则顺延到下一个开市日调仓。
4. 其他交易日 `select_signals` 直接返回空列表，不刷新目标池。

交易日历属于事前可知信息，策略可以用它判断交易周边界；价格、财务和宽表指标仍严格按交易时点可见性裁剪。

## 2. 市场环境过滤

策略在信号日先计算小市值近似股票池的牛熊指标，环境不利时直接空信号：

1. 每个交易日先按策略基础约束过滤普通主板非 ST、上市满 250 日、EPS 非负、价格和流通市值有效的股票。
2. 在过滤后的股票中按 `circ_mv` 取最小的 500 只，样本不足 300 只时视为数据不足并空仓。
3. 每日牛熊指标 = top500 平均换手率 + top500 平均收益率的 20 日波动率。
4. 对牛熊指标计算 10 日短均线和 40 日长均线。
5. 短均线在长均线之上视为处于最近一次金叉之后，正常选股；短均线在长均线之下视为处于最近一次死叉之后，空仓。

该指标使用动态 top500 小市值池，刻画的是当时小市值生态的活跃度，而不是固定指数走势。

## 3. 收盘后选信号

信号日 T 收盘后，策略读取截至 T 日的完整宽表数据，生成最新目标池：

1. 排除上市不足 250 天的次新股。
2. 排除科创板、创业板、北交所、ST、`*ST`。
3. 最近一个季度 EPS 小于 0 的股票排除。
4. 使用不复权收盘价 `close`，筛选全市场最低价 10% 股票。
5. 在低价池内按 `circ_mv` 从小到大排序，选取指定排名区间作为目标池。

当前参数：

```text
target_holdings = 10
low_price_quantile = 10%
circ_mv_rank_start = 1
circ_mv_rank_end = 10
```

## 4. 卖出决策

回测系统在每日 T 交易阶段调用策略卖出函数。策略只使用 T 日可观察行情字段，不使用 T 日 MA、ATR 等收盘后宽表指标。

卖出规则：

1. 每天检查持仓，如果上一交易日涨停，T 日没有继续涨停，则按 T 日收盘价卖出。
2. 只在交易周第一个开市日执行周频调仓。
3. 调仓日开盘时，持仓不在最新目标池内则卖出。
4. 如果调仓日开盘涨停，则不因调仓卖出，继续持有。
5. 目标池内已有持仓会尽量调回等权，超配则在调仓日开盘减仓。

## 5. 买入决策

回测系统在每日卖出后调用策略买入函数。策略使用卖出后的现金池，乐观假设当日卖出资金可用于当日买入。

买入规则：

1. 只在交易周第一个开市日开盘执行买入。
2. 使用上一交易周最后一个开市日收盘后生成并保存在观望池中的目标池。
3. 目标持仓等权分配。
4. 调仓日开盘涨停或跌停的股票不买。
5. 上一交易日涨停或跌停的股票不买。
6. 停牌、零成交量、无有效行情、一字板等流动性枯竭标的不买。

## 6. 观望池更新

交易周最后一个开市日 T 收盘后，策略把当日最新目标池写入观望池。下一交易周第一个开市日开盘买入时实际使用的是 T 日收盘后已经确定的目标池。

若市场环境过滤为空信号，观望池会被清空；下一交易周第一个开市日调仓时，持仓不在目标池内会按调仓规则卖出。

## 7. 无未来函数约束

1. 选信号阶段模拟 T 收盘后，可以使用 T 日完整宽表。
2. 卖出和买入阶段只使用 T 日开盘、最高、最低、收盘、成交量、涨跌幅、前收盘等交易中可观察字段。
3. 卖出和买入阶段不得使用 T 日 MA、ATR、均量等收盘后宽表指标。
4. 周频调仓使用上一交易周最后一个开市日收盘后生成的目标池。
5. 交易日历只用于判断交易周第一个和最后一个开市日，不读取 T 日之后的股票行情、财务数据或宽表指标。
