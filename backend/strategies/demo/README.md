# Demo 策略

`demo` 是当前小市值低价轮动策略的带探针副本，用于压测、调试和对照正式策略行为。它保留正式策略已经下掉的冗余字段和历史探针，但交易规则与小市值基准保持一致。

## 1. 策略定位

1. 每个交易日 T 收盘后计算一次目标池信号。
2. 买入和周频调仓只在自然周一开盘执行。
3. 不启用指数择时、Top500 牛熊指标、金叉死叉或其他市场环境过滤。
4. 默认单次回测，便于和 `small_float_value` 对照。

## 2. 保留的探针能力

相对正式 `small_float_value`，`demo` 继续保留以下压测/调试内容：

1. 信号阶段声明 `qfq_close`、`total_mv` 等展示字段。
2. `signal_history_window = 200`。
3. `select_signals` 会通过 `view.iter_stock_history(window=200)` 探测入选股票历史窗口，校验信号视图没有未来数据。
4. 买入信号会附带 `buy_history_probe`，包括 T-1 历史窗口长度、最后日期、最近复权收盘价和 5/10 日历史收益。

这些字段不参与正式选股或交易判断，只用于观察数据装载和无未来函数裁剪是否符合预期。

## 3. 选股和交易规则

1. 排除上市不足 250 天的次新股。
2. 排除科创板、创业板、北交所、ST、`*ST`。
3. 最近一个季度 EPS 小于 0 的股票排除。
4. 使用不复权收盘价 `close`，筛选全市场最低价 10% 股票。
5. 在低价池内按 `circ_mv` 从小到大排序，选取第 1-10 名作为目标池。
6. 周一开盘调仓，目标持仓等权。
7. 上一交易日涨停、T 日未继续涨停时按 T 日收盘价卖出。

## 4. 无未来函数约束

1. 选信号阶段模拟 T 收盘后，可以使用 T 日完整宽表。
2. 信号历史探针只允许看到 `trade_date <= T` 的窗口。
3. 卖出和买入阶段只使用 T 日交易可观察字段，以及截至 T-1 的历史宽表窗口。
4. `buy_history_probe` 只记录买入阶段可见的 T-1 历史信息，不读取调仓日 T 收盘后的宽表指标。
