# 急涨回踩龙头战术

注册名：`sharp_rise_pullback_leader`

该策略用于捕捉已经进入多头趋势、近期出现前高后回踩、随后尝试二次启动的个股。信号函数在 T 日收盘后运行；买入、卖出和观察池更新只使用当日可观察行情和信号日冻结字段，避免未来函数。

## 一、信号函数

基础过滤：

1. 股票范围：保留 `sh.6`、`sz.0`、`sz.3`，排除科创板 `sh.688` 和北交所。
2. 排除名称包含 `ST` 的股票，且要求 `is_st = 0`。
3. 未复权收盘价 `close >= 12`。
4. 换手率 `turnover_rate >= 5%`。
5. 必须具备前复权 OHLC、`MA10`、`MA20`、`MA30` 等字段。

趋势与回踩结构：

1. 最近 16 个交易日全部满足 `MA10 > MA20 > MA30`。
2. 当前多头排列段至少连续 15 个交易日。
3. 在最近 16 个交易日内寻找最新最高点 D。
4. D 到 T 的距离必须为 3 到 7 个交易日。
5. 在 D 到 T 区间内寻找最低点 L，L 的最低价相对 D 高点回踩幅度必须为 5% 到 15%。
6. L 的前复权最低价和前复权收盘价都必须严格低于 T 日前复权收盘价。
7. L 到 T 之间，不允许任何一天的前复权收盘价高于 T 日前复权收盘价，要求 T 是 L 之后的收盘右侧确认。
8. T 日前复权收盘价必须位于 `MA10 * 0.94` 到 `MA10 * 1.02` 之间。

信号会冻结：

- T 日前复权收盘价、最低价、最高价、MA10、MA20。
- 最近 16 日高点 D 的日期和价格。
- D 到 T 区间的最低点 L 日期、最低价 `pattern_floor_low` 和收盘价。
- D 高点到 L 低点的回踩幅度。
- 买入触发价 `entry_trigger_price = T close * 1.025`。
- 最大观察天数 `max_watch_days = 3`。

## 二、买入函数

观察期为 T+1 到 T+5，最多 5 个交易日。

买入规则：

1. 只从观察池中买入尚未持仓、尚未过期的信号。
2. 买入触发价固定为 `T close * 1.025`。
3. 买入必须由观察日盘中价格真实触达触发价，不能用乐观价格成交。
4. 若观察日开盘价高于买入触发价，且盘中最低价也高于买入触发价，说明全天持续高于买入价，不买入。
5. 若观察日价格区间覆盖买入触发价，即 `observation_day qfq_low <= entry_trigger_price <= observation_day qfq_high`，则按买入触发价买入。
6. 若观察日开盘价低于或等于买入触发价，且盘中最高价达到或超过买入触发价，也按买入触发价买入。
7. 若同一观察日多个信号触发，按回测轮次和交易日生成的可复现随机顺序买入。
8. 每笔目标买入金额为当前总资产的 33%，按 100 股整数手向下取整。

观察池移除：

1. 已买入的股票移出观察池。
2. 观察满 5 个交易日仍未买入的股票移出观察池。
3. 观察期内允许收盘走低，只要观察日收盘价不跌破 `pattern_floor_low`，就继续保留。
4. 观察期内若收盘价跌破 `pattern_floor_low`，收盘后移出观察池。
5. 观察期内只要盘中最高价达到或超过买入触发价，不管是否实际买入，收盘后都移出观察池；高开越过买点且全天不回落的信号也会移除。

## 三、卖出函数

卖出只对已经持有至少 1 个交易日的仓位生效。

优先级从高到低：

1. 结构低点收盘止损  
   若持仓后任一交易日的前复权收盘价跌破信号日冻结的 `pattern_floor_low`，按当日前复权收盘价卖出。

2. 收盘走弱退出  
   若当日前复权收盘价相对前一交易日前复权收盘价涨幅 `<= 3%`，按当日收盘价卖出。不再要求当天盘中最大浮盈达到某个阈值。

## 五、无未来函数约束

1. 信号选择在 T 日收盘后运行，只读取 `trade_date <= T` 的宽表数据。
2. 买入阶段只使用观察日可见的开、高、低、收等行情字段，以及信号日冻结的买入触发价和结构低点。
3. 卖出阶段只使用当前持仓状态、信号日冻结字段和当日前复权收盘价。
4. 买入和卖出阶段不读取 T 日之后的宽表指标。
