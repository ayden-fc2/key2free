# 事件驱动的回测系统

本文记录当前回测统计模块的实现约定。目标是复用信号系统，按交易日顺序驱动信号、观望、买入、持仓、卖出和资金变化，尽量避免因为当天信号当天买入、最新股票池覆盖历史股票池等问题引入未来函数。

## 前端入口

回测统计页面提供以下参数：

- 回测周期：默认 `2018-01-01` 到 `2026-05-13`。
- 初始仓位：默认 `100000` 元。
- 策略：默认 `demo`。

点击开始回测后，后端在 `meta.my_task` 中创建一条 `type = backtest` 的任务记录。回测任务允许重复创建，同一个参数可以多次运行，所有回测结果表都用 `task_id` 区分。

每个回测任务固定执行 50 轮随机撮合。信号预计算只执行一次；50 轮共享同一个 `task_id` 和同一批预计算信号，买入订单、卖出订单和每日快照通过 `run_no` 区分不同随机撮合结果。

## 任务流程

1. 根据回测周期从 `source.trade_calendar` 获取交易日。
2. 使用信号系统按股票维度分批预计算信号；每只股票只加载一次回测区间内的股票池和前复权日 K，再对区间内所有交易日扫描，避免按日期重复读取全市场数据。
3. 将每个交易日爆出的信号写入 `meta.backtest_signal`，通过 `task_id` 关联本次回测任务。
4. 创建并清理本次任务对应的买入订单、卖出订单和每日快照记录。
5. 生成本次任务的随机种子。
6. 固定执行 50 轮事件撮合，每轮现金池、持仓池和观望池都从初始状态重新开始。
7. 每轮撮合结果写入订单表和每日快照表，并用 `run_no` 标记轮次。

## 回测结果表

### `meta.backtest_signal`

保存预计算信号：

- `task_id`：回测任务 ID。
- `trade_date`：信号日。
- `strategy_name`：策略名。
- `code`、`code_name`：股票代码和名称。
- `universe_json`：信号系统返回的股票池上下文摘要。
- `signal_json`：标准化信号对象，包含 `triggered`、`min_stop_loss`、`reference_take_profit`、`signal_atr30`、`ideal_buy_price`、`max_watch_days` 等字段。

### `meta.backtest_buy_order`

保存买入订单：

- `task_id`、`run_no`、`trade_date`、`code`、`code_name`。
- `buy_price`、`quantity`、`amount`、`fee`、`cash_after`。
- `signal_json`：触发本次观望/买入的信号对象。

### `meta.backtest_sell_order`

保存卖出订单：

- `task_id`、`run_no`、`trade_date`、`code`、`code_name`。
- `sell_price`、`quantity`、`amount`、`fee`、`cash_after`。
- `buy_date`、`buy_price`、`pnl`。

### `meta.backtest_daily_snapshot`

保存每日快照：

- `task_id`、`run_no`、`trade_date`。
- `total_asset`、`cash`、`holding_market_value`。
- `holding_count`、`watch_count`。
- `holding_json`：持仓池明细。
- `watch_json`：观望池明细。

## 日级运行逻辑

回测维护三个池：

- 现金池：初始值来自前端输入。
- 持仓池：保存代码、名称、买入日期、买入价格、数量、最低止损、参考止盈、信号日 ATR30。
- 观望池：保存代码、名称、加入日期、加入交易日序号、最低止损、参考止盈、信号日 ATR30、理想买入价格、最长观望时长。

每天按照固定顺序执行：

1. 处理持仓池。
   - 跳过当日刚买入的股票，保证不做当日买当日卖。
   - 读取当日 `mart.bar_1d_qfq` 的 OHLC。
   - 调用选中策略的卖出函数，传入 `open_price`、`close_price`、`high_price`、`low_price`、`buy_date`、`min_stop_loss`、`reference_take_profit`、`signal_atr30`。
   - 返回 `-1` 表示不卖；返回数字则按该价格卖出，并更新卖出订单、现金池和持仓池。
2. 处理观望池。
   - 使用 `任务随机种子 + run_no + trade_date` 打乱观望池执行顺序，降低单次随机顺序造成的偶然性。
   - 跳过当日刚进入观望池的股票，保证信号日不能当日买入。
   - 调用选中策略的买入函数，传入 `open_price`、`close_price`、`high_price`、`low_price`、`min_stop_loss`、`reference_take_profit`、`signal_atr30`、`ideal_buy_price`。
   - 返回 `-1` 表示继续观望；如果超过最长观望交易日，则从观望池移除。
   - 返回数字则按该价格买入，更新买入订单、现金池、持仓池和观望池。
3. 根据提前计算好的当日信号更新观望池。
   - 已在持仓池或观望池中的股票不重复加入。
   - 新信号只进入观望池，不允许当天买入。
4. 写入每日快照。

## 成本和仓位

- 买入费率 `buy_fee_bps = 5`。
- 卖出费率 `sell_fee_bps = 10`。
- 当前每笔买入最多使用当日估算总资产的 `1/3`，并按 100 股整数手计算数量。

## 策略函数规范

策略注册包含三个函数：

- 信号函数：输入 `StockDataContext`，返回布尔值或标准信号对象。
- 买入函数：输入当日 OHLC 和观望池信号参数，返回 `-1` 或成交价格。`-1` 表示继续观望或等待回测系统按最长观望时长移除；数字表示按该价格买入。
- 卖出函数：输入当日 OHLC 和持仓池参数，返回 `-1` 或成交价格。`-1` 表示继续持仓；数字表示按该价格卖出。

当前 demo 买入函数规则：

- 输入字段：`open_price`、`close_price`、`high_price`、`low_price`、`min_stop_loss`、`reference_take_profit`、`signal_atr30`、`ideal_buy_price`。
- 如果开盘价格高于理想买入价，返回开盘价格。
- 否则如果理想买入价落在当日最高价和最低价区间内，返回理想买入价。
- 否则返回 `-1`。

当前 demo 卖出函数规则：

- 输入字段：`open_price`、`close_price`、`high_price`、`low_price`、`buy_date`、`min_stop_loss`、`reference_take_profit`、`signal_atr30`。
- 如果最低止损落在当日最高价和最低价区间内，返回最低止损。
- 否则如果参考止盈落在当日最高价和最低价区间内，返回参考止盈。
- 否则如果 `open_price - signal_atr30 * 0.618` 落在当日最高价和最低价区间内，返回该价格。
- 否则返回 `-1`。

## 避免未来函数的约束

- 信号系统在 `T` 日只读取 `T` 及以前的数据。
- 回测先处理历史持仓和历史观望池，再把 `T` 日新信号加入观望池。
- 当日新信号不能当日买入，当日新买入不能当日卖出。
- 股票池使用选中日期对应的快照/上下文，不使用最新静态股票表覆盖历史。
- 当前 `mart.bar_1d_qfq` 使用维护到最新的 `adjust_factor` 计算前复权价格，暂不做复权因子 `as_of_date=T` 版本化；因此当前版本适合个人复盘和策略原型验证，严格无未来函数回测暂不保证复权因子口径。
