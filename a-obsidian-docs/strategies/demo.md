# demo 策略

## 一、策略总览

##### 1. 策略核心思想

demo 的核心是“三段式确认”：

1. **成分过滤**：只看当前策略定义下适合观察的普通 A 股。
2. **趋势过滤**：得到MA30区间低点，确保过去4个区间低点落在过去144-400交易日内，并符合震荡/走强结构；同时要求近期低点仍在L4支撑区附近、MA20斜率短期改善。MACD 背离过滤当前暂时关闭，保留函数但不参与信号筛选。
3. **K 线过滤**：按照金k理论，在 T 日确认转折或重新走强信号。

> [!note]
> [!note]
> 策略要求 T 附近最低价仍围绕最近结构低点 L4 的 ATR 区间，不追明显跌破 L4 后继续走弱的票；同时不要求 T 日必须精确踩在某条均线或平台位。

##### 5. 筛选结构

`demo_signal_strategy` 按顺序执行以下筛选，任一层不通过则返回 `False`：

1. 成分筛选。
2. 趋势筛选。
3. K 线筛选。

只有三层全部通过时，才返回 `True`。

## 二、信号规则

### 1. 成分筛选

只保留普通 A 股：

- `security_type == 1`。
- `list_status == 1`。
- 排除科创板：`sh.688*`。
- 排除创业板：`sz.300*`、`sz.301*`。
- 排除 ST：股票名称包含 `ST`、`*` 或 `＊` 时剔除。
- 代码需属于主板形态：`sh.6*` 或 `sz.0*`。

### 2. 趋势筛选

基于 `bars_1d_qfq` 计算：

- 截取 T-430 ~ T 区间，过去400个交易日内的MA30做滚动线性拟合，找到斜率从负转正的点位，确保数量在 5 - 10 次
- 最近5个点位中间形成了4个区间，在这4个区间内分别得到其最低价（影线价），得到L1 ~ L4，并且对于L所在日，计算得到ATR30，分别是ATR30(L1~L4)
- L1 -> L2，L2 -> L3, L3 -> L4 的价格变化，根据后者的ATR30计算。统一使用 `1 * ATR30` 作为结构噪音阈值：上涨超过 `1 * ATR30(后一个低点)` 记录为“涨”；下跌超过 `1 * ATR30(后一个低点)` 记录为“跌”；否则记录为“震”。得到C12，C23，C34的变化幅度后，只保留“震震震”、“跌震涨”、“跌涨震”、“跌涨涨”、“震涨涨”、“涨震涨”、“涨涨震”、“震震涨”、“涨震震”、“震涨震”、“涨涨涨”
- 确保当前T ~ T-5内，价格最低点落在 L4 附近。附近区间使用 ATR 口径：`L4 - 1.618 * ATR30(L4) <= recent_low <= L4 + 1.0 * ATR30(L4)`。下沿使用黄金扩展位容忍短期回踩、影线刺破或轻微破位；上沿允许价格从 L4 附近开始右侧修复但仍处在一个正常波动单位内。
- 确保 T 日收盘价仍在合理买点区间，而不是只在 T ~ T-5 曾经踩过 L4。如果低点结构中“涨”的数量不少于 2，允许 `close_T <= L4 + 1.618 * ATR30(L4)`；否则要求 `close_T <= L4 + 1.0 * ATR30(L4)`。
- 确保 T 日收盘价仍靠近最近支撑，而不是从最近低点已经反弹过远：`close_T <= recent_low(T-5..T) + 1.2 * ATR30(L4)`。
- 确保从 L4 所在日到 T 的完整右侧区间内，价格没有真实破坏 L4 支撑：`min(close[L4..T]) >= L4 - 1.0 * ATR30(L4)` 且 `min(low[L4..T]) >= L4 - 1.618 * ATR30(L4)`。这用于过滤 MA30 延后导致的结构误判，同时允许单日影线刺破。
- 计算MA20，并对MA20做滚动线性拟合；要求最近 5 日中至少 3 次相邻 MA20 斜率改善。这里不要求斜率必须为正，只要求下行斜率整体收敛或上行斜率整体增强，用于确认 T 附近开始修复。
- MACD 背离过滤当前暂时关闭，保留计算函数但不参与当前信号筛选。

### 3. K 线筛选

满足如下k线形态之一，表明是入场信号：

- 蜻蜓线：T 日实体高度不超过总高度 10%；下影线为长影线，上影线为短影线，且下影线 / 上影线>=6；T 日成交量 >= `0.8 * 过去10日成交量平均值`。
- 锤形线：T 日实体高度占总高度 10% ~ 40%；下影线为长影线，上影线为短影线，且下影线 / 上影线 >= 4；T 日成交量 >= `0.8 * 过去10日成交量平均值`。
- 启明之星：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；`T-4 ~ T-2` 中存在一个最左侧大阴线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；大阴线和 T 日之间夹 1 ~ 3 根小线，小线震荡高度不超过 `0.6 * ATR14`。
- 看涨吞没：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 是阴线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 实体高度至少达到 T 日实体高度的 61.8%，且 T-1 的实体区间被 T 日实体区间完全吞没。吞没类形态强调“阳包阴/阴包阳”的实体压制力，实体占比不使用黄金分割放宽。
- 刺绣：当前暂时关闭，不参与当前信号筛选。
- 仙人指路：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 是倒锤形线，实体高度占总高度 10% ~ 40%，上影线为长影线，下影线为短影线，且上影线 / 下影线 >= 4；T 日收盘价必须高于 T-1 最高价。

## 信号策略输入

`demo_signal_strategy` 接收信号系统构造的 `StockDataContext`。其中 `bars_1d_qfq` 默认包含该股票在 `T` 及以前所有交易日的前复权日线历史。这个上下文也可作为后续回测渲染、均线绘制、MACD 绘制和其他指标 utils 的统一数据基准。

当前 demo 在注册表中配置了当日信号历史窗口，后端执行 `/signals/daily` 时只会为 demo 读取每只股票 `T` 及以前最近 430 根前复权日线。该窗口覆盖 `T-430 ~ T`、过去 400 个交易日 MA30 结构、ATR30、ATR14、成交量均值和 120 日 MACD 背离所需数据，不读取 `T` 之后的数据，因此不引入未来函数。前端图表用的 `stock-contexts` 接口仍会拉取数据库中的全量 `StockDataContext`。

## 注册方式

在 `STRATEGY_REGISTRY` 中注册：

```python
"demo": StrategyRegistration(
    name="demo",
    signal_strategy=demo_signal_strategy,
    entry_strategy=demo_entry_strategy,
    exit_strategy=demo_exit_strategy,
    universe_filter=demo_universe_filter,
    daily_signal_history_limit=430,
)
```

前端选择策略时使用同一个注册名 `demo`。

## 后续扩展准则

- 新策略应复制 `demo` 的目录结构。
- 每个策略必须提供信号策略、入场策略、出场策略三个函数。
- 策略注册名应稳定，前端和后端都用注册名识别策略。
- 信号策略只判断是否爆信号，不处理资金、仓位、成交、止盈止损。
- 入场策略和出场策略当前仍是占位接口，等回测模块确定输入输出后再补充。
