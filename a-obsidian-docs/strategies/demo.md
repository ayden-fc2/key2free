# demo 策略

> 本文记录 demo 战法的当前实现口径。后端注册名为 `demo`，信号策略位于 `backend/strategies/demo/strategy.py`。

## 一、信号过滤

信号过滤分为三层：

1. 成分过滤
2. N 字结构过滤
3. 其他过滤

### 1. 成分过滤

只看普通 A 股：

- 排除科创板。
- 排除创业板。
- 排除 ST。
- 只保留主板普通股票。

### 2. N 字结构过滤

目标形态记录三个关键点：

```text
L1(tl1, pl1) -> H1(th1, ph1) -> L2(tl2, pl2)
```

其中：

- `t` 表示交易日位置。
- `p` 表示前复权盘中价。
- `L1`：第一低点，使用前复权日内最低价定位。
- `H1`：反弹高点，使用前复权日内最高价定位。
- `L2`：第二低点，使用前复权日内最低价定位。
- `T`：信号确认日，所有结构识别只使用 `T` 及以前数据。

#### 2.1 MA10 斜率区间识别

结构层使用宽表中的 `ma_slope_10`。该指标是 MA10 的单日变化率，小数口径，不乘 100。

设扰动阈值为：

```text
m = 0.005
```

即：

```text
ma_slope_10 > m   视为 up
ma_slope_10 < -m  视为 down
-m <= ma_slope_10 <= m 视为扰动区，扫描时按兵不动
```

从 `T` 开始向前扫描 `ma_slope_10`，维护交替出现的斜率极值区间：

1. 初始化 `k_down(0)`、`k_up(0)` 都为空。
2. 从 `T` 往前取 `k = ma_slope_10`。
3. 若当前尚未进入阶段：
   - 遇到 `k > m`，进入 `up` 阶段，并维护当前 `k_up`。
   - 遇到 `k < -m`，进入 `down` 阶段，并维护当前 `k_down`。
   - 若 `k` 落在 `[-m, m]`，忽略。
4. 若处于 `up` 阶段：
   - 遇到更大的正斜率，则更新当前 `k_up`。
   - 直到遇到 `k < -m`，封存当前 `k_up`，进入新的 `down` 阶段。
5. 若处于 `down` 阶段：
   - 遇到更小的负斜率，则更新当前 `k_down`。
   - 直到遇到 `k > m`，封存当前 `k_down`，进入新的 `up` 阶段。
6. 一直扫描到策略传入窗口的最早交易日，得到一组按时间交替排列的斜率极值点：

```text
... -> k_down -> k_up -> k_down -> k_up ...
```

#### 2.2 由斜率区间定位 L/H

拿到交替斜率极值后，按时间从前往后生成结构点：

```text
k_down -> k_up 区间：取区间内前复权最低价，定位 L
k_up -> k_down 区间：取区间内前复权最高价，定位 H
```

若从 `T` 往前扫描时，最近一段尚未形成新的反向 `k_up`，即最新极值为 `k_down`，则补充终端段：

```text
k_down -> T 区间：取区间内前复权最低价，定位最新 L
```

这用于识别“下跌结束后斜率进入扰动区、价格贴底整理”的 L2。该规则只使用 `T` 及以前数据，不引入未来函数。

然后从生成的结构点里，选取距离 `T` 最近的一组：

```text
L1 -> H1 -> L2
```

若没有完整的 `L -> H -> L`，则不出信号。

#### 2.3 N 字硬过滤

找到最近的 `L1/H1/L2` 后，只做两条结构硬过滤：

```text
H1 - L1 >= L1 * 0.20
L1 - 2 * ATR14(T) <= L2 <= L1 + 1 * ATR14(T)
L2 + 0.1 * (H1 - L2) <= close(T) <= L2 + 0.3 * (H1 - L2)
```

含义：

- `H1 - L1 >= L1 * 0.20` 要求第一段相对 L1 至少反弹 20%。
- `L2` 必须回到 `L1` 附近，允许向下刺破 `2 * ATR14(T)`，向上偏离不超过 `1 * ATR14(T)`。
- T 日收盘必须重新站回 `L2` 之上至少 10% 的结构空间，但不能超过 30%，避免利润空间被挤压太多。
- 这里的 `L1/H1/L2` 使用前复权盘中高低价，不再使用收盘价。

### 3. 其他过滤

#### 3.1 成交量收缩

T 日 10 日均量需要相对 H1 之后的 5 日均量明显收缩：

```text
avg_volume_10(T) <= 1/4 * avg_volume_5(th1 + 2)
```

含义：

- `avg_volume_10(T)` 使用信号日 T 的 10 日平均成交量。
- `avg_volume_5(th1 + 2)` 使用 H1 日期后第 2 个交易日的 5 日平均成交量。
- 使用 `th1 + 2` 而不是 th1 当天，是为了避免单日放量尖峰过于偶然，并与波动收缩的基准保持一致。
- 该条件要求二次回落确认时量能明显低于第一段反弹高点后的量能水平。

#### 3.2 波动收缩

T 日 ATR14 需要相对 H1 之后的 ATR5 明显收缩：

```text
ATR14(T) <= 1/3 * ATR5(th1 + 2)
```

含义：

- `ATR14(T)` 使用信号日 T 的 14 日 ATR。
- `ATR5(th1 + 2)` 使用 H1 日期后第 2 个交易日的 5 日 ATR。
- 使用 `th1 + 2` 而不是 th1 当天，是为了避免急涨刚出现时 ATR5 尚未充分反映反弹段波动，导致基准偏小。
- 该条件要求 L2 附近进入更低波动状态，过滤高波动下跌中的反抽。

## 二、买入操作

### 1. 入场

T+1 直接按照开盘价买入。

这里的 `T+1` 指下一个交易日，不是自然日。例如周五 `T` 日爆出信号，若下周一为正常交易日，则下周一按开盘价买入。

### 2. 止损

止损只设置一档：

```text
stop_loss = L2 - 0.15 * (H1 - L2)
```

按照回测框架的通用做法：

- 当日收盘价低于或等于止损位时触发止损。
- 触发后按照当日收盘价卖出。

### 3. 止盈

止盈只设置一档：

```text
take_profit = H1 - 0.15 * (H1 - L2)
```

### 4. 盈亏比过滤

根据 T 日收盘价与止损、止盈的距离计算盈亏比：

```text
risk = close(T) - stop_loss
reward = take_profit - close(T)
reward_risk_ratio = reward / risk
```

若：

```text
reward_risk_ratio < 1.5
```

则不做。

### 5. 仓位

demo 使用风险敞口定仓，并叠加单票市值上限：

```text
(close(T) - stop_loss) * quantity <= total_asset * 2%
buy_price * quantity <= total_asset * 1/4
```

其中：

- `close(T)` 为信号日 T 的前复权收盘价。
- `buy_price` 为 T+1 实际开盘成交价。
- `quantity` 向下取整到 100 股整数手。
- 同时受可用现金约束，含买入手续费。

## 三、其他

### 1. 最长持仓

最长持仓 40 个交易日。

若买入后第 40 个交易日收盘仍未触发止盈或止损，则按回测框架通用逻辑强制卖出。
