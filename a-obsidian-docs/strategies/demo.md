# demo 策略

> 本文记录 demo 战法的当前实现口径。后端注册名为 `demo`，信号策略位于 `backend/strategies/demo/strategy.py`。

## 一、信号过滤

信号过滤分为三层：

1. 成分过滤
2. 趋势结构过滤
3. K 线形态过滤

### 1. 成分过滤

只看普通 A 股。

当前普通 A 股口径：

- 排除科创板。
- 排除创业板。
- 排除 ST。
- 只保留主板普通股票。

### 2. 趋势结构过滤

#### 2.1 N 字结构

目标形态必须符合 N 字结构，并记录三个关键点：

```text
L1(tl1, pl1) -> H1(th1, ph1) -> L2(tl2, pl2)
```

其中：

- `t` 表示时间。
- `p` 表示收盘价。
- `L1(tl1, pl1)`：第一低点。
- `H1(th1, ph1)`：反弹高点。
- `L2(tl2, pl2)`：第二低点。

#### 2.2 形态大小硬过滤

形态必须满足：

```text
ph1 - pl1 >= 3 * ATR14(T)
T - tl1 >= 10 个交易日
-ATR14(T) <= pl2 - pl1 <= ATR14(T)
```

含义：

- 第一段反弹高度必须足够，至少达到 `3 * ATR14(T)`。
- 从 `L1` 到 `T` 至少经过 10 个交易日，避免把很小的日内噪音识别成 N 字结构。
- `L2` 收盘价允许轻微高于或低于 `L1`，但偏离不能超过 `1 * ATR14(T)`。

### 3. K 线形态过滤

#### 3.1 形态集合

在 `(tl2 - 3)` 到 `T` 之间，需要出现下列 K 线结构之一：

- 蜻蜓线
- 锤形线
- 启明之星
- 看涨吞没
- 仙人指路
- 红三兵

并且该 K 线结构内部的最低价（日内最低价）必须满足：

```text
形态内最低价 <= pl2 + 0.2 * ATR14(T)
```

#### 3.2 L2 到 T 的距离

`tl2` 到 `T` 的距离固定为 2 个交易日：

```text
T - tl2 = 2
```

#### 3.3 T 日收盘位置

T 日收盘价必须满足：

```text
pl2 <= close(T) <= pl2 + 0.3 * (ph1 - pl2)
```

含义：

- T 日收盘必须重新收回到 `L2` 之上。
- 但 T 日收盘不能距离 `L2` 太远，避免追高。

## 二、买入操作

### 1. 入场

T+1 直接按照开盘价买入。

这里的 `T+1` 指下一个交易日，不是自然日。例如周五 `T` 日爆出信号，若下周一为正常交易日，则下周一按开盘价买入。

### 2. 止损

止损只设置一档：

```text
stop_loss = pl2 - 0.8 * ATR14(T)
```

按照回测框架的通用做法：

- 当日收盘价低于或等于止损位时触发止损。
- 触发后按照当日收盘价卖出。

### 3. 止盈

止盈只设置一档：

```text
take_profit = ph1 - 0.5 * ATR14(T)
```

### 4. 盈亏比过滤

根据 T 日收盘价与止损、止盈的距离计算盈亏比：

```text
risk = close(T) - stop_loss
reward = take_profit - close(T)
reward_risk_ratio = reward / risk
```

若：

```text
reward_risk_ratio < 1.3
```

则不做。

### 5. 仓位

demo 使用风险敞口定仓，并叠加单票市值上限：

```text
(close(T) - stop_loss) * quantity <= total_asset * 2%
buy_price * quantity <= total_asset * 1/4
```

其中：

- `close(T)` 为信号日 T 的前复权收盘价。
- `buy_price` 为 T+1 实际开盘成交价。
- `quantity` 向下取整到 100 股整数手。
- 同时受可用现金约束，含买入手续费。

## 三、其他

### 1. 最长持仓

最长持仓 20 个交易日。

若买入后第 20 个交易日收盘仍未触发止盈或止损，则按回测框架通用逻辑强制卖出。
