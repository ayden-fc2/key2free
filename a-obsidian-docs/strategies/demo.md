# demo 策略

## 一、策略总览

##### 1. 策略核心思想

demo 的核心是"三段式确认"：

1. **成分过滤**：只看当前策略定义下适合观察的普通 A 股。
2. **趋势过滤**：得到MA30区间低点，确保过去4个区间低点落在过去144-400交易日内，并符合震荡/走强结构；同时要求近期低点仍在L4支撑区附近、MA20斜率短期改善。MACD 背离过滤当前暂时关闭，保留函数但不参与信号筛选。
3. **K 线过滤**：按照金k理论，在 T 日确认转折或重新走强信号。

> [!note]
> 策略要求 T 附近最低价仍围绕最近结构低点 L4 的 ATR 区间，不追明显跌破 L4 后继续走弱的票；同时不要求 T 日必须精确踩在某条均线或平台位。

##### 4. 策略函数

| 函数 | 类型 | 当前行为 |
| --- | --- | --- |
| `demo_batch_signal_strategy` | 信号策略 | 接收单只股票宽表列式数据和目标评估位置，执行成分筛选、趋势筛选和 K 线筛选，返回 `SignalDecision`。 |
| `demo_code_filter` | 代码级预过滤 | 静态筛主板普通 A 股代码形态（排除科创板/创业板），用于在读取历史窗口前缩小股票池；ST 等与交易日相关的条件在信号函数内基于宽表 `is_st`、`name` 列判断。 |
| 入场策略 | 框架默认 | `signal_close` 限价买入语义，最多观望 2 个交易日，见 [[3.  事件驱动的回测系统#日级运行逻辑]]。 |
| 出场策略 | 框架默认 | 通用阶梯止盈止损引擎，两档止损/止盈，见下文。 |

##### 5. 信号决策字段

`demo_signal_strategy` 三层筛选全部通过时，返回 `SignalDecision(triggered=True, ...)`，字段取值：

| 字段 | demo 取值 | 说明 |
| --- | --- | --- |
| `signal_close` | `T` 日前复权收盘价 | 确认买入价：观望期内价格触及该价即成交。 |
| `stop_losses[0]` | `L4 - 1.618 × ATR30(L4)` | 第一止损位：与入场逻辑的噪音容忍带（黄金扩展位）对齐——入场允许影线刺破到该位置，止损就必须放在它之外。旧 `1.0 × ATR30` 口径下约半数止损单在 20 个交易日内收复买入价（被洗出局），故下移。 |
| `stop_losses[1]` | `signal_close` | 第二止损位：买入价（保本止损）。 |
| `take_profits[0]` | `signal_close + 1.5 × (signal_close - stop_losses[0])` | 第一止盈位（随第一止损位同步变化）。 |
| `take_profits[1]` | `signal_close + 2 × (signal_close - stop_losses[0])` | 第二止盈位（随第一止损位同步变化）。 |
| `max_watch_days` | `2` | 最多观望 2 个交易日。 |
| `extras` | `{"signal_atr30": ATR30(L4), "l4_low": L4, "l3_l4_max_close": ..., ...}` | 复盘参考值，不参与撮合。 |

**止盈可达性过滤**：第二止盈位（最终目标）必须低于 `L3 ~ L4` 区间的最高收盘价（前高阻力）。若 `take_profits[1] >= max(close[L3..L4])`，说明止盈计划撞上阻力位、盈亏目标不现实，信号作废（`triggered=False`）。

出场语义（由框架阶梯引擎执行）：

- 初始档位 0：触发 `stop_losses[0]` 全部卖出；触发 `take_profits[0]` 卖出一半（向上取整到百股，仅 100 股则全部卖出），随后止损/止盈同时切换到档位 1。
- 档位 1：触发 `stop_losses[1]`（买入价保本位）全部卖出；触发 `take_profits[1]` 全部卖出。

入场语义（由框架默认入场执行）：信号日后最多观望 2 个交易日，开盘价 `<= signal_close` 按开盘价买入；盘中触及 `signal_close` 按 `signal_close` 买入；2 日内未触及则移出观望池。

## 二、信号规则

### 1. 成分筛选

只保留普通 A 股（基于宽表 `T` 日行字段）：

- 排除科创板：`sh.688*`。
- 排除创业板：`sz.300*`、`sz.301*`。
- 排除 ST：`is_st == 1`，或股票名称包含 `ST`、`*`、`＊`。
- 代码需属于主板形态：`sh.6*` 或 `sz.0*`。

### 2. 趋势筛选

基于 400 根宽表窗口计算，**MA30、ATR30、MA20 直接使用宽表预计算列 `ma_30`、`atr_30`、`ma_20`**，策略内只做拟合和结构识别：

- 对窗口内 400 个交易日的 `ma_30` 做 10 日滚动线性拟合，找到斜率从负转正的点位，确保数量在 5 - 10 次。
- 最近 5 个点位中间形成了 4 个区间，在这 4 个区间内分别得到其最低价（影线价 `qfq_low`），得到 L1 ~ L4；并对于 L 所在日，取宽表 `atr_30` 得到 ATR30(L1~L4)。
- L1 -> L2，L2 -> L3, L3 -> L4 的价格变化，根据后者的 ATR30 计算。统一使用 `1 * ATR30` 作为结构噪音阈值：上涨超过 `1 * ATR30(后一个低点)` 记录为"涨"；下跌超过 `1 * ATR30(后一个低点)` 记录为"跌"；否则记录为"震"。得到 C12，C23，C34 的变化幅度后，只保留"震震震"、"跌震涨"、"跌涨震"、"跌涨涨"、"震涨涨"、"涨震涨"、"涨涨震"、"震震涨"、"涨震震"、"震涨震"、"涨涨涨"（2026-06 曾试验放宽为"仅排除最后一段下跌"并缩短跨度到 100，两年回测胜率与终值均下滑，已回退）。
- L1 到 L4 的跨度不少于 144 个交易日。
- 确保当前 T ~ T-5 内，价格最低点落在 L4 附近。附近区间使用 ATR 口径：`L4 - 1.618 * ATR30(L4) <= recent_low <= L4 + 1.0 * ATR30(L4)`。下沿使用黄金扩展位容忍短期回踩、影线刺破或轻微破位；上沿允许价格从 L4 附近开始右侧修复但仍处在一个正常波动单位内。
- 确保 T 日收盘价仍在合理买点区间，而不是只在 T ~ T-5 曾经踩过 L4。如果低点结构中"涨"的数量不少于 2，允许 `close_T <= L4 + 1.618 * ATR30(L4)`；否则要求 `close_T <= L4 + 1.0 * ATR30(L4)`。
- 确保 T 日收盘价仍靠近最近支撑，而不是从最近低点已经反弹过远：`close_T <= recent_low(T-5..T) + 1.2 * ATR30(L4)`。
- 确保从 L4 所在日到 T 的完整右侧区间内，价格没有真实破坏 L4 支撑：`min(close[L4..T]) >= L4 - 1.0 * ATR30(L4)` 且 `min(low[L4..T]) >= L4 - 1.618 * ATR30(L4)`。这用于过滤 MA30 延后导致的结构误判，同时允许单日影线刺破。
- 对宽表 `ma_20` 做 10 日滚动线性拟合；要求最近 5 日中至少 3 次相邻 MA20 斜率改善。这里不要求斜率必须为正，只要求下行斜率整体收敛或上行斜率整体增强，用于确认 T 附近开始修复。
- **右侧位置确认**：T 日宽表 `boll_percent_b_20_2 >= 0.25`，要求价格已脱离布林下轨，避免贴轨"接刀"（回测归因：盈单买入日 %B 中位 0.34，亏单 0.20）。
- **长期跌幅下限**：T 日宽表 `roc_120 >= -20%`，过深的下跌趋势不参与，"筑底"更可能是下跌中继（归因：亏单 roc_120 中位 -10.9%，盈单 -7.4%）。
- MACD 背离过滤当前暂时关闭，保留计算函数但不参与当前信号筛选（启用时可直接使用宽表 `macd_dif_12_26_9`、`macd_hist_12_26_9` 列）。

> [!note] 窗口说明
> 旧实现窗口为 430 根（400 根结构 + 30 根 MA30 预热）。切换到宽表后 `ma_30` 已预计算、无需预热，统一为 400 根窗口；窗口首行 `ma_30` 为 `null`（个股上市初期）时保守不出信号。

### 3. K 线筛选

满足如下 K 线形态之一，表明是入场信号。形态判定**优先使用宽表 K 线结构列**：`body_range_ratio`（实体/总高度）、`upper_shadow_range_ratio`、`lower_shadow_range_ratio`、`atr_14`、`avg_volume_10`、`volume_ratio_10`：

- 蜻蜓线：T 日实体高度不超过总高度 10%；下影线为长影线，上影线为短影线，且下影线 / 上影线 >= 6；T 日成交量 >= `0.8 * 过去10日成交量平均值`。
- 锤形线：T 日实体高度占总高度 10% ~ 40%；下影线为长影线，上影线为短影线，且下影线 / 上影线 >= 4；T 日成交量 >= `0.8 * 过去10日成交量平均值`。
- 启明之星：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；`T-4 ~ T-2` 中存在一个最左侧大阴线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；大阴线和 T 日之间夹 1 ~ 3 根小线，小线震荡高度不超过 `0.6 * ATR14`。
- 看涨吞没：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 是阴线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 实体高度至少达到 T 日实体高度的 61.8%，且 T-1 的实体区间被 T 日实体区间完全吞没。吞没类形态强调"阳包阴/阴包阳"的实体压制力，实体占比不使用黄金分割放宽。
- 刺绣：当前暂时关闭，不参与当前信号筛选。
- 仙人指路：T 日是阳线，实体高度占总高度至少 80%，且实体高度不低于 `0.618 * ATR14`；T-1 是倒锤形线，实体高度占总高度 10% ~ 40%，上影线为长影线，下影线为短影线，且上影线 / 下影线 >= 4；T 日收盘价必须高于 T-1 最高价。

注：成交量条件中"过去 10 日平均"不含 T 日；宽表 `avg_volume_10` 含当日，使用时取 T-1 行的 `avg_volume_10`。

## 信号策略输入

`demo_signal_strategy` 接收信号系统传入的单只股票 400 根宽表窗口（[[2. 信号系统#传给信号策略的数据]]）。窗口覆盖过去 400 个交易日的 MA30 结构、ATR30、ATR14、成交量均值所需数据，不读取 `T` 之后的数据，因此不引入未来函数。

前端当日信号页拿到 demo 信号后，会再批量拉取这些股票的全量历史，并通过可复用图表组件渲染日 K、MA5/MA10/MA20/MA30、MACD 和成交量。图表默认显示最后 60 个交易日，三个视图共享缩放拖动。

## 注册方式

在 `STRATEGY_REGISTRY` 中注册：

```python
"demo": StrategyRegistration(
    name="demo",
    batch_signal_strategy=demo_batch_signal_strategy,  # 逐股批量评估
    required_columns=DEMO_REQUIRED_COLUMNS,            # 策略需要的宽表列
    code_filter=demo_code_filter,                      # 代码级静态预过滤
    # 入场/出场缺省使用框架默认实现（signal_close 限价 + 阶梯止盈止损引擎）
)
```

前端选择策略时使用同一个注册名 `demo`。

## 后续扩展准则

- 新策略应复制 `demo` 的目录结构。
- 每个策略必须提供信号策略函数；入场/出场可缺省使用框架默认实现。
- 策略注册名应稳定，前端和后端都用注册名识别策略。
- 信号策略返回标准 `SignalDecision`（含 `signal_close`、`stop_losses`、`take_profits` 数组），不处理资金、仓位、成交等交易动作。
- 资金、仓位、手续费、撮合边界和订单写入由回测模块统一处理。
