# 黄金柱战法

> 本文记录新版黄金柱战法的目标口径。后端注册名暂沿用 `golden_pillar`，当前文档先作为策略实现前的设计稿。

## 一、策略思想

目标形态是“七周大白马 + 黄金柱”：

1. T 日以前处于一段明确下跌趋势，并且价格已经处在相对低位。
2. 下跌后出现较长时间的缩量、缩幅整理，说明抛压衰减。
3. T 日突然出现强实体大阳线，确认资金重新进场。
4. T+1 只在开盘价没有明显高于 T 日收盘价时买入，避免高开追价。

这套策略与 demo 不同：demo 找的是深跌后的 N 字回踩，黄金柱找的是下跌衰竭后的短周期启动柱。缩量缩幅阶段的左侧必须衔接下跌趋势，而不是上涨趋势后的高位横盘。

## 二、信号过滤

信号过滤分为四层：

1. 成分过滤
2. 左侧下跌与低位过滤
3. 缩量缩幅过滤
4. T 日黄金柱过滤

### 1. 成分过滤

只看普通 A 股：

- 排除科创板。
- 排除创业板。
- 排除 ST。
- 只保留主板普通股票。

### 2. 左侧下跌与低位过滤

T 日之前必须先有一段 `/\` 结构：左侧下跌到 L1，随后反弹到 H1，再重新回落到 L2。结构识别复用 demo 策略的 `2.1 MA10 斜率区间识别`，但识别截止日使用 `T-1`，不能使用 T 日黄金柱或 T+1 数据。

结构点定义：

```text
L1(tl1, pl1) -> H1(th1, ph1) -> L2(tl2, pl2)
```

其中：

- `ma_slope_10 > m` 视为 up。
- `ma_slope_10 < -m` 视为 down。
- `-m <= ma_slope_10 <= m` 视为扰动区。
- `m = 0.008`。
- `k_down -> k_up` 区间取前复权最低价，定位 L。
- `k_up -> k_down` 区间取前复权最高价，定位 H。
- 若最新极值为 `k_down`，则补充 `k_down -> T-1` 终端段，在该区间取前复权最低价作为最新 L。

找到最近一组 `L1 -> H1 -> L2` 后，允许 T 位于 L2 之后、下一个 H 之前。也就是说，L2 不必正好出现在 T-1 附近，只要 L2 之后尚未形成新的结构高点，就仍可视作处在同一轮低位整理/启动区。

同时要求 T-1 仍处在结构低位，保留足够上涨空间：

```text
close(T-1) <= H1 - 0.4 * (H1 - L1)
```

含义：

- `L1/H1/L2` 用来确认左侧确实经历过“下跌 -> 反弹 -> 回落”的 `/\` 结构。
- `close(T-1)` 不能超过 `L1 -> H1` 结构空间的 60% 位置，确保距离 H1 仍有一定上涨空间。
- 这里只做 T-1 的低位确认，T 日必须留给黄金柱本身验证。

### 3. 缩量缩幅过滤

缩量缩幅不再使用固定 6~7 天窗口，而是复用上一步识别出的 `H1` 作为反弹高点基准，要求 T-1 相比 H1 明显收缩。

#### 3.1 缩量

T-1 的 5 日均量需要明显低于 H1 之后的 5 日均量：

```text
avg_volume_5(T-1) <= 0.5 * avg_volume_5(th1 + 2)
```

含义：

- `avg_volume_5(T-1)` 表示黄金柱爆发前的短期成交量水平。
- `avg_volume_5(th1 + 2)` 表示左侧反弹高点后第 2 个交易日的短期成交量基准。
- 使用 `th1 + 2` 而不是 th1 当天，是为了避免单日放量尖峰过于偶然，并与波动收缩的基准保持一致。
- 该条件要求回落到 L1 附近时成交量已经明显衰减，抛压下降。

#### 3.2 缩幅

T-1 的短期波动需要明显低于 H1 之后的短期波动：

```text
ATR5(T-1) <= 0.5 * ATR5(th1 + 2)
```

含义：

- `ATR5(T-1)` 表示黄金柱爆发前最近 5 日波动。
- `ATR5(th1 + 2)` 表示左侧反弹高点后第 2 个交易日的短期波动基准。
- 使用 `th1 + 2` 而不是 th1 当天，是为了避免急涨刚出现时 ATR5 尚未充分反映反弹段波动，导致基准偏小。
- 该条件要求回落支撑区已经进入低波动状态，过滤仍在剧烈下跌或宽幅震荡中的票。

#### 3.3 本地震荡幅度

T 日之前最近 15 个交易日必须是相对窄幅整理：

```text
local_high = max(qfq_high[T-15, T-1])
local_low = min(qfq_low[T-15, T-1])
(local_high - local_low) / local_low <= 15%
```

含义：

- 只使用 `T-15 ~ T-1` 的前复权高低价，不使用 T 日或 T+1 数据。
- 该条件用于过滤 L2 后已经走出明显小波段的票，要求黄金柱启动前有一段更长的本地窄幅震荡。
- 因为最近 15 个交易日整体振幅已经被压到 15% 以内，所以不再额外设置“柱前 15 日无大阳柱”过滤。

### 4. T 日黄金柱过滤

T 日必须是一根强实体大阳线：

```text
qfq_close(T) > qfq_open(T)
(qfq_close(T) - qfq_open(T)) / qfq_open(T) >= 5%
qfq_close(T) - qfq_open(T) >= 1.6 * ATR5(T-1)
```

关键价位：

```text
pillar_open = qfq_open(T)
pillar_close = qfq_close(T)
pillar_body = qfq_close(T) - qfq_open(T)
```

含义：

- `pillar_body / qfq_open(T) >= 5%` 保证 T 日实体自身足够强，不再要求收盘价相对 T-1 收盘涨幅必须达到 6%。
- `pillar_body >= 1.6 * ATR5(T-1)` 保证 T 日实体相对启动前的低波动状态足够大。
- 使用实体高度作为后续止盈止损基准，不使用影线高低点。

## 三、买入操作

### 1. 入场

T 日收盘后只生成候选信号，T+1 开盘时再判断是否真正买入。

买入条件：

```text
open(T+1) <= pillar_close * 1.03
```

若满足，则按 T+1 开盘价买入：

```text
buy_price = open(T+1)
```

若 T+1 开盘价高于 T 日收盘价 3% 以上，则放弃该信号，不顺延。低开不再因开盘价偏离而过滤。

这里的 `T+1` 指下一个交易日，不是自然日。例如周五 T 日爆出候选信号，若下周一为正常交易日，则下周一开盘判断是否买入。

### 2. 阶梯止盈止损

黄金柱使用两段阶梯止盈止损。回测框架的通用阶梯语义为：

- 初始使用第 1 段止盈和第 1 段止损。
- 盘中触及第 1 段止盈时，卖出约一半仓位，并将剩余仓位升到第 2 段。
- 升到第 2 段后，剩余仓位使用第 2 段止盈和第 2 段止损。
- 止盈按盘中触及成交；止损按收盘价确认，并按收盘价卖出。

关键价格：

```text
stop_loss_1 = pillar_open + 0.5 * pillar_body
stop_loss_2 = pillar_close + pillar_body
take_profit_1 = pillar_close + pillar_body
take_profit_2 = pillar_close + 2 * pillar_body
```

### 3. 最长持仓

最长持仓 15 个交易日。

若买入后第 15 个交易日收盘仍未触发止盈或止损，则按收盘价强制卖出。

## 四、决策字段

黄金柱的实际买入价取决于 T+1 开盘价，因此 T 日信号需要携带 T 日可确定的柱体信息，并由回测框架在成交时落定买入价、止盈和止损。

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `signal_close` | `pillar_close` | T 日收盘价，仅作为 T+1 开盘过滤基准 |
| `max_watch_days` | `1` | 只观察 T+1 一个交易日 |
| `extras.pillar_open` | `qfq_open(T)` | T 日开盘价 |
| `extras.pillar_close` | `qfq_close(T)` | T 日收盘价 |
| `extras.pillar_body` | `qfq_close(T) - qfq_open(T)` | T 日实体高度 |
| `extras.pillar_body_open_ratio` | `pillar_body / qfq_open(T)` | T 日实体涨幅 |
| `extras.entry_open_max` | `pillar_close * 1.03` | T+1 最高可接受开盘价 |

成交后落定：

```text
buy_price = open(T+1)
quantity = 不超过当前总资产 1/4 的最大 100 股整数倍，且受可用现金与买入手续费约束
stop_losses = [pillar_open + 0.5 * pillar_body, pillar_close + pillar_body]
take_profits = [pillar_close + pillar_body, pillar_close + 2 * pillar_body]
max_holding_days = 15
```

## 五、实现注意

1. 所有信号判断只能使用 T 日及以前数据，T+1 只用于入场成交确认。
2. 左侧缩量缩幅必须衔接下跌趋势，不能只判断“最近几日安静”。
3. 缩量缩幅优先使用宽表已有均量、ATR、振幅类指标，避免逐 K 重复计算。
4. T 日黄金柱使用前复权开收盘价计算实体，止盈止损也沿用同一价格口径。
5. 若股票已在持仓或观察池中，重复信号应由回测框架忽略，避免重复买入。
