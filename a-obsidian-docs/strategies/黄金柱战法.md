# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径。

# 一、结构定义
### 1. 黄金柱、将军柱结构体：
一根破量大阳线，后面跟着三根缩量无论阴阳的短实体线（或者两根缩量无论阴阳的线和一根破量大阳线）
如果后面跟着的三根的线的实体中点的平均值大于第一根破量大阳线的收盘价，那就是黄金柱，如果在第一根大阳线的实体的前 2/3区域，那就是将军柱

具体的，对于需要校验的区间 t1,t2,t3,t4
t1的成交量>= 1.2*avg_volume_5(t0)
t1的实体高度>=min(0.04*t1开盘, atr_5(t0)*1.5)
t2和t3的实体高度均 <= 0.5*t1实体高度
t4的实体高度 <= 0.5*t1实体高度 或者 1.2 * t1实体高度 >= t4实体高度 >= 0.5*t1实体高度且t4为上涨
最后根据t2,t3,t4的实体中间价的平均价格与 t1收盘价 比较得知这段是黄金柱或将军柱

### 2. 长横盘震荡区间
固定在30个交易日的区间内，其平均日k振幅<=3%，其区间内最大振幅<=10%

对于策略输入的过去几百天交易日，滑动窗口获得所有将军柱和黄金柱的区域，
滑动窗口得到所有横盘震荡区间（注意连续符合条件的情况下会有重叠，例如连续40天符合条件，那就会有10个重叠的震荡区间）

# 二、入场信号
接下来是信号，必须满足如下条件才报信号
1. T-10 ~ T内，包含至少一个横盘震荡区间的结束点
2. T-10 ~ T内，包含至少一个黄金柱或将军柱
3. T收盘价 >= 震荡区间最高价 * 1.03

# 三、入场、止盈、止损

这时候T+1开盘价入场，
第一段止损放在 震荡区间（最高价+最低价）/ 2 的中位价格
第二段止损放在T收盘价*1.03

第一段止盈先按 (T收盘价-第一段止损) * 1.5 + T收盘价 计算，然后限制在 T收盘价*1.06 到 T收盘价*1.10 之间，意思是盈亏比1.5但是止盈下限6%、上限10%
第二段止盈先按 (T收盘价-第一段止损) * 2.2 + T收盘价 计算，然后限制在 T收盘价*1.09 到 T收盘价*1.15 之间，意思是盈亏比2.2但是止盈下限9%、上限15%

最长持仓15交易日
