# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径，策略信号以 T 日收盘后生成，T+1 只用于开盘成交确认。

## 一、策略思想

目标形态是“下跌衰竭后的黄金柱启动”：

1. T 日以前处于下跌后的低位整理区。
2. 左侧出现较长时间缩量、缩幅，说明抛压衰减。
3. T 日出现强实体阳线，确认资金重新进场。
4. T+1 开盘价不能明显偏离 T 日收盘价，否则放弃信号。

这套策略不是 demo 的 N 字回踩突破，而是抓低位整理后的第一根启动柱。

## 二、信号过滤

### 1. 成分过滤

只看主板普通 A 股：

- 排除科创板。
- 排除创业板。
- 排除 ST。
- 只保留 `sh.6`、`sz.0` 主板普通股票。

### 2. 左侧下跌与低位过滤

T 日之前必须先有一段 `/\` 结构：

```text
L1(tl1, pl1) -> H1(th1, ph1) -> L2(tl2, pl2)
```

结构识别复用 demo 策略的 MA10 斜率区间识别，但截止日使用 `T-1`，不能使用 T 日黄金柱或 T+1 数据。

规则：

```text
ma_slope_10 > 0.008   => up
ma_slope_10 < -0.008  => down
-0.008 <= ma_slope_10 <= 0.008 => noise
```

- `k_down -> k_up` 区间取前复权最低价，定位 L。
- `k_up -> k_down` 区间取前复权最高价，定位 H。
- 如果最新极值为 `k_down`，补充 `k_down -> T-1` 终端段，在该区间取最低价作为最新 L。

找到最近一组 `L1 -> H1 -> L2` 后，允许 T 位于 L2 之后、下一个 H 之前。也就是说，L2 不必正好出现在 T-1 附近，只要 L2 之后尚未形成新的结构高点，就仍可视作同一轮低位整理启动区。

低位要求：

```text
close(T-1) <= H1 - 0.4 * (H1 - L1)
```

### 3. 缩量缩幅过滤

缩量缩幅以 `H1 + 2` 作为前高后的参考点，避免 H1 当天 ATR 或均量统计偏小。

```text
avg_volume_10(T-1) <= 0.5 * avg_volume_10(th1 + 2)
ATR14(T-1) <= 0.5 * ATR14(th1 + 2)
ER20(T-1) <= 0.40
```

含义：

- T-1 前处于低方向效率整理状态。
- T-1 相比 H1 后的放量反弹阶段明显缩量。
- T-1 相比 H1 后的波动阶段明显缩幅。

### 4. T 日黄金柱过滤

T 日必须是一根强实体阳线：

```text
pillar_open = qfq_open(T)
pillar_close = qfq_close(T)
pillar_body = qfq_close(T) - qfq_open(T)

pillar_body / qfq_open(T) >= 5%
pillar_body >= 1.6 * ATR14(T-1)
ER20(T) <= 0.30
```

说明：

- 实体涨幅下限保证 T 日足够强。
- `1.6 * ATR14(T-1)` 保证启动柱明显强于整理期波动。
- `ER20(T) <= 0.30` 避免 T 日方向效率过高、短线情绪已经打满。

## 三、买入与退出

### 1. 入场

T 日收盘后只生成候选信号，T+1 开盘时判断是否买入。

```text
pillar_close * 0.98 <= open(T+1) <= pillar_close * 1.03
```

满足条件时按 T+1 开盘价买入：

```text
buy_price = open(T+1)
```

若 T+1 开盘价高于 T 日收盘价 3% 以上，或低于 T 日收盘价 2% 以上，则放弃该信号，不顺延。

这里的 `T+1` 指下一个交易日，不是自然日。例如周五 T 日爆出候选信号，若下周一为正常交易日，则下周一开盘判断是否买入。

### 2. 仓位

买入股数为不超过当前总资产 1/4 的最大 100 股整数倍，并受可用现金与买入手续费约束。

### 3. 止盈止损

黄金柱使用两段阶梯止盈止损：

- 止盈按盘中触及成交。
- 止损按收盘价确认，并按收盘价卖出。
- 第一段止盈触及后卖出约一半仓位，并把剩余仓位的止损切换到 T 日收盘价。
- 第二段止盈触及后卖出剩余仓位。

退出单位对 T 日柱体高度做 9% 封顶，避免大柱子把止盈止损拉得过远：

```text
exit_unit = min(pillar_body, pillar_close * 9%)

stop_loss_1 = pillar_open + 0.5 * exit_unit
take_profit_1 = pillar_close + exit_unit
stop_loss_2 = pillar_close
take_profit_2 = pillar_close + 2 * exit_unit
```

### 4. 最长持仓

最长持仓 15 个交易日。

若买入后第 15 个交易日收盘仍未触发止盈或止损，则按收盘价强制卖出。

## 四、决策字段

T 日信号携带 T 日可确定的信息，回测框架在 T+1 成交后落定买入价、止盈和止损。

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `signal_close` | `pillar_close` | T 日收盘价，仅作为 T+1 开盘过滤基准 |
| `max_watch_days` | `1` | 只观察 T+1 一个交易日 |
| `extras.tl1/pl1` | `L1` | 左侧低点 |
| `extras.th1/ph1` | `H1` | 左侧反弹高点 |
| `extras.tl2/pl2` | `L2` | 回落低点 |
| `extras.avg_volume10_t_minus_1` | `avg_volume_10(T-1)` | T 前一日 10 日均量 |
| `extras.avg_volume10_th1_plus2` | `avg_volume_10(th1 + 2)` | H1 后第 2 个交易日 10 日均量 |
| `extras.atr14_t_minus_1` | `ATR14(T-1)` | T 前一日 ATR14 |
| `extras.atr14_th1_plus2` | `ATR14(th1 + 2)` | H1 后第 2 个交易日 ATR14 |
| `extras.er20_t_minus_1` | `ER20(T-1)` | T 前 20 日方向效率，要求不高于 0.40 |
| `extras.er20_t` | `ER20(T)` | T 日方向效率，要求不高于 0.30 |
| `extras.pillar_open` | `qfq_open(T)` | T 日开盘价 |
| `extras.pillar_close` | `qfq_close(T)` | T 日收盘价 |
| `extras.pillar_body` | `qfq_close(T) - qfq_open(T)` | T 日实体高度 |
| `extras.pillar_body_open_ratio` | `pillar_body / qfq_open(T)` | T 日实体涨幅 |
| `extras.entry_open_min` | `pillar_close * 0.98` | T+1 最低可接受开盘价 |
| `extras.entry_open_max` | `pillar_close * 1.03` | T+1 最高可接受开盘价 |

成交后落定：

```text
buy_price = open(T+1)
quantity = 不超过当前总资产 1/4 的最大 100 股整数倍，且受可用现金与买入手续费约束
exit_unit = min(pillar_body, pillar_close * 9%)
stop_losses = [pillar_open + 0.5 * exit_unit, pillar_close]
take_profits = [pillar_close + exit_unit, pillar_close + 2 * exit_unit]
max_holding_days = 15
```

## 五、实现注意

1. 所有信号判断只能使用 T 日及以前数据，T+1 只用于入场成交确认。
2. 左侧缩量缩幅必须衔接下跌趋势，不能只判断“最近几日安静”。
3. 缩量缩幅优先使用宽表均量、ATR、ER 等指标，避免逐 K 重复计算。
4. T 日黄金柱使用前复权开收盘价计算实体，止盈止损也沿用同一价格口径。
5. 若股票已在持仓或观察池中，重复信号应由回测框架忽略，避免重复买入。
