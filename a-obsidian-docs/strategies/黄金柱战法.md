# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径。

## 一、结构定义

### 1. 黄金柱、将军柱

对于连续 4 个交易日 `t1,t2,t3,t4`：

- `t1` 是破量大阳线：`volume(t1) >= 1.4 * avg_volume_5(t0)`。
- `t1` 实体高度满足：`body(t1) >= min(0.032 * open(t1), 1.5 * ATR5(t0))`，且 `body(t1) <= 0.08 * open(t1)`。
- `t2,t3` 是短实体：`body <= 0.5 * body(t1)`。
- `t4` 可以是短实体；如果不是短实体，则必须是阳线，且 `body(t4) <= 0.08 * open(t4)`。
- `t2,t3,t4` 的实体最高价不得超过 `1.06 * close(t1)`，避免柱体确认阶段价格已经冲得过高。
- 将 `t2,t3,t4` 的实体位置映射到 `t1` 实体高度内：
  - 实体最低位置都在 `80%` 以上，为黄金柱。
  - 实体最低位置都在 `40%` 以上、实体最高位置都在 `80%` 以下、实体中点均值在 `60%` 以上，为将军柱。

### 2. 横盘震荡区间

横盘区间固定为 20 个交易日，使用宽表与窗口内价格共同判断：

- 20 日收盘价区间振幅：`(max(close) - min(close)) / min(close) <= 8%`。
- 20 日平均实体高度：`avg(abs(close - open) / close) <= 2.2%`。
- 横盘区间最后一天 `er_20 <= 0.22`。

横盘区间必须在柱体 `t1` 之前结束；信号日附近只取最近的合格横盘。

## 二、信号条件

信号日 `T` 必须同时满足：

1. `T` 对应的最近结构刚好构成一个黄金柱或将军柱后的确认平台，即允许 `T` 是 `t4` 到 `t4+4`。
2. `t1` 收盘价必须站上横盘实体高点：

```text
close(t1) >= 1.02 * 横盘实体最高点
```

3. `t2,t3,t4` 三天中至少两天收盘价站上：

```text
close >= 1.02 * 横盘实体最高点
```

4. `T` 必须是结构结束后首次明确站上 `close(t1)` 压力位的确认日：

```text
close(T) >= 1.01 * close(t1)
且 t4 ~ T-1 内没有任何一天 close >= 1.01 * close(t1)
```

5. 柱后确认平台不能破坏柱体支撑：

```text
t4+1 ~ T 内，low >= open(t1)
```

## 三、入场、出场

信号出现后观察 `T+1 ~ T+3`，任一观察日记为 `D`。

当 `D` 日开盘价满足：

```text
0.98 * close(T) <= open(D) <= 1.04 * close(T)
```

且日内价格冲到：

```text
max(1.01 * close(T), 1.01 * open(D))
```

时买入。实际买入价不得超过：

```text
1.04 * close(T)
```

买入后只持仓 1 个交易日，按下一交易日收盘价卖出。

仓位使用固定比例定仓，单票买入市值不超过总资产的 `1/4`。
