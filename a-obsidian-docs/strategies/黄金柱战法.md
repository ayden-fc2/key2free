# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径。

## 一、结构定义

### 1. 黄金柱、将军柱结构

对于需要校验的区间 `t1,t2,t3,t4`：

- `t1` 必须是破量大阳线。
- `t2,t3` 必须是短实体线，阴阳不限；`t4` 可以是短实体线，也可以是阳实体线。
- `t1` 成交量 `>= 1.3 * avg_volume_5(t0)`。
- `t1` 实体高度 `>= min(0.03 * t1开盘价, atr_5(t0) * 1.5)`。
- `t1` 实体高度 `<= 0.08 * t1开盘价`。
- `t2,t3` 的实体高度均 `<= 0.03 * t1收盘价`。
- `t4` 的实体高度可以 `<= 0.03 * t1收盘价`；如果 `t4` 实体高度 `>= 0.03 * t1收盘价`，则 `t4` 必须是阳实体。

柱类型按 `t2,t3,t4` 的实体在 `t1` 实体中的位置判断：

- 黄金柱：`t2,t3,t4` 的收盘价均 `>= t1实体下沿 + 0.8 * t1实体高度`。
- 将军柱：`t2,t3,t4` 的收盘价均 `>= t1实体下沿 + 0.5 * t1实体高度`。

### 2. 长横盘震荡区间

固定使用 20 个交易日的区间。

区间需要满足：

- 平均日 K 实体振幅 `<= 3.0%`。
- 区间实体通道最大振幅 `<= 8.0%`。

实体通道计算口径：

- 排除区间内一个最高实体点和一个最低实体点。
- 每根 K 线实体高点 = `max(开盘价, 收盘价)`。
- 每根 K 线实体低点 = `min(开盘价, 收盘价)`。
- 实体通道最大振幅 = `(实体通道最高值 - 实体通道最低值) / 实体通道最低值`。

策略会在输入窗口内滑动扫描所有黄金柱、将军柱和长横盘震荡区间。

### 3. N 字结构（用于止盈止损空间分级）

使用宽表中的 `ma_slope_10`，该指标是 MA10 的单日变化率，小数口径，不乘 100。

扰动阈值：

```text
m = 0.008
```

判定：

```text
ma_slope_10 > m   视为 up
ma_slope_10 < -m  视为 down
-m <= ma_slope_10 <= m 视为扰动区，扫描时忽略
```

从 `T` 向前扫描 `ma_slope_10`，维护交替出现的斜率极值区间，并按时间顺序生成结构点：

```text
k_down -> k_up   区间：取区间内前复权最低收盘价，定义为 L
k_up   -> k_down 区间：取区间内前复权最高收盘价，定义为 H
```

止盈止损分级使用前方 N 字压力位：

- 从 `T` 向前扫描结构点，找到第一个 `H > T收盘价 * 1.1` 的高点。
- 若未找到该 `H`，视为上方没有明确 N 字压力，保留两级止盈止损。
- 若找到该 `H`，使用 `H * 0.95` 作为前高压力折扣线。

## 二、入场信号

必须同时满足：

1. 结束一段长震荡：`T-6 ~ T` 内，包含至少一个长横盘震荡区间的结束点。
2. 迎来明显的将军柱：`T-6 ~ T` 内，包含至少一个黄金柱或将军柱。
3. 确定破位：`T` 收盘价 `>= 震荡区间实体通道最高值 * 1.02`，且 `<= 震荡区间实体通道最高值 * 1.10`。
4. 控制爆量衰竭：`T` 日 `volume_ratio_20 <= 3.5`。

## 三、入场、止盈、止损

非高开入场：`T+1` 开盘价入场，且 `T+1` 开盘价必须 `<= T收盘价 * 1.04`，否则放弃买入。

- 第一段止损：长震荡区间内所有 K 线实体中点价格的平均值，实体中点价格 = `(开盘价 + 收盘价) / 2`。
- 第二段止损：`T收盘价 * 1.05`。
- 第一段止盈：`T收盘价 * 1.08`。
- 第二段止盈：`min(T收盘价 * 1.12, T收盘价 + (T收盘价 - 第一段止损价) * 2)`。

N 字压力位分级：

- 如果第一段止盈价 `>= H * 0.95`，说明空间不足，直接不做。
- 如果第二段止盈价 `>= H * 0.95`，但第一段止盈价 `< H * 0.95`，只使用一级止盈止损。
- 如果第二段止盈价 `< H * 0.95`，使用两级止盈止损。

持仓时间：

- 最长持仓 `15` 个交易日。
- 买入后第 `4` 个交易日，如果收盘价仍未达到 `买入价 * 1.04`，说明没有赌到启动，则在第 `4` 个交易日收盘价卖出。
