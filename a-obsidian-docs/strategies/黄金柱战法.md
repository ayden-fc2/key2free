# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径。

# 一、结构定义
### 1. 黄金柱、将军柱结构体：
一根破量大阳线，后面跟着三根缩量无论阴阳的短实体线
如果后面跟着的三根的线的实体部分均落在第一根破量大阳线的80%高度以上，那就是黄金柱，如果在第一根大阳线的实体40%~80%区域且均值在60%以上，那就是将军柱

具体的，对于需要校验的区间 t1,t2,t3,t4
t1放量：t1的成交量>= 1.4 * avg_volume_5(t0)
t1涨幅大，并符合3.2%~8%区间：t1的实体高度>=min(0.032 * t1开盘, atr_5(t0) * 1.5)，且t1的实体高度 <= 0.08 * t1开盘
t2, t3的实体高度均 <= 0.03 * t1收盘价；t4可以是短实体，也可以是阳实体，但t4阳实体高度不能超过0.08 * t4开盘价
最后根据t2,t3,t4的实体价格与 t1 比较得知这段是黄金柱或将军柱

### 2. 长横盘震荡区间
固定在14个交易日的区间内，其平均日k实体振幅<=2.7%（满足最后一天atr14<=3.2%)，其区间内最大振幅（实体，按收盘价区间计算）<=7.2%

对于策略输入的过去几百天交易日，滑动窗口获得所有将军柱和黄金柱的区域，
滑动窗口得到所有横盘震荡区间（注意连续符合条件的情况下会有重叠，例如连续24天符合条件，那就会有10个重叠的震荡区间）

### 3. N字扫描
使用宽表中的 `ma_slope_10`。该指标是 MA10 的单日变化率，小数口径，不乘 100。

设扰动阈值为：

```text
m = 0.008
```

即：

```text
ma_slope_10 > m   视为 up
ma_slope_10 < -m  视为 down
-m <= ma_slope_10 <= m 视为扰动区，扫描时按兵不动
```

从 `T` 开始向前扫描 `ma_slope_10`，维护交替出现的斜率极值区间：

1. 初始化 `k_down(0)`、`k_up(0)` 都为空。
2. 从 `T` 往前取 `k = ma_slope_10`。
3. 若当前尚未进入阶段：
   - 遇到 `k > m`，进入 `up` 阶段，并维护当前 `k_up`。
   - 遇到 `k < -m`，进入 `down` 阶段，并维护当前 `k_down`。
   - 若 `k` 落在 `[-m, m]`，忽略。
4. 若处于 `up` 阶段：
   - 遇到更大的正斜率，则更新当前 `k_up`。
   - 直到遇到 `k < -m`，封存当前 `k_up`，进入新的 `down` 阶段。
5. 若处于 `down` 阶段：
   - 遇到更小的负斜率，则更新当前 `k_down`。
   - 直到遇到 `k > m`，封存当前 `k_down`，进入新的 `up` 阶段。
6. 一直扫描到策略传入窗口的最早交易日，得到一组按时间交替排列的斜率极值点：

```text
... -> k_down -> k_up -> k_down -> k_up ...
```


拿到交替斜率极值后，按时间从前往后生成结构点：

```text
k_down -> k_up 区间：取区间内前复权最低收盘价，定位 L
k_up -> k_down 区间：取区间内前复权最高收盘价，定位 H
```

接着我们根据T日的ma_slope_10，
1. <-m，说明T处在下行趋势
2. >m，说明T处在上涨趋势
3. 在-m和m之间，说明T处于最近极值点后的震荡趋势（高点震荡或低点震荡）

# 二、信号
接下来是信号，必须满足如下条件才报信号
1. 有横盘震荡区间：T-5 ~ T内，包含至少一个横盘震荡区间的结束点
2. 是柱体结构：T-6 ~ T内，包含至少一个黄金柱/将军柱形态
3. 柱体突破确认：T，T-1，T-2这三天收盘价里至少两天 >= 1.02 * 14天横盘结构的实体最高点

# 三、入场、出场

拿到信号后进入候选池，T+1开始最长观察4交易日
当开盘价格满足 `主体结构t1收盘价 * 1.1 >= 当日开盘价 >= 主体结构t1收盘价 * 0.96` 时，日内价格冲到 `max(t1收盘价 * 1.01, 当日开盘价 * 1.01)` 时买入

买入后下一交易日执行卖出：

- 如果下一交易日开盘价 `>= 买入价 * 1.02`，开盘卖出。
- 如果下一交易日开盘价 `<= 买入价 * 0.98`，开盘卖出。
- 如果下一交易日开盘价在买入价的 `-2% ~ +2%` 之间，收盘卖出。
