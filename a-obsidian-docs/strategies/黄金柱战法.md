# 黄金柱战法

> 后端策略名：`golden_pillar`。本文记录当前实现口径。

## 一、结构定义

### 1. 黄金柱

对于连续 4 个交易日 `t1,t2,t3,t4`：

- `t1` 是破量大阳线：`volume(t1) >= 1.4 * avg_volume_5(t0)`。
- `t1` 实体高度满足：`body(t1) >= min(0.032 * open(t1), 1.5 * ATR5(t0))`，且 `body(t1) <= 0.08 * open(t1)`。
- `t2,t3` 是短实体：`body <= 0.5 * body(t1)`。
- `t4` 可以是短实体；如果不是短实体，则必须是阳线，且 `body(t4) <= 0.08 * open(t4)`。
- `t2,t3,t4` 的实体最高价不得超过 `1.06 * close(t1)`，避免柱体确认阶段价格已经冲得过高。
- 将 `t2,t3,t4` 的实体位置映射到 `t1` 实体高度内：
  - 实体最低位置都在 `100%` 以上，为黄金柱。
  - 将军柱不作为当前策略信号。

### 2. 横盘震荡区间

横盘区间固定为 15 个交易日，使用窗口内价格判断：

- 15 日收盘价区间振幅：`4% <= (max(close) - min(close)) / min(close) <= 7%`。
- 15 日平均实体高度：`avg(abs(close - open) / close) <= 2.5%`。

横盘区间必须在柱体 `t1` 之前结束；`t1` 前 5 个交易日内允许有横盘结束点，信号日附近只取最近的合格横盘。

## 二、信号条件

信号日 `T` 必须同时满足：

1. `T` 对应的最近结构刚好构成一个黄金柱，即 `T == t4`。
2. `t1` 收盘价必须站上横盘实体高点：

```text
1.05 * 横盘实体最高点 >= close(t1) >= 1.02 * 横盘实体最高点
```

3. `t2,t3,t4` 三天中至少两天收盘价站上：

```text
close >= 1.02 * 横盘实体最高点
```

4. `T` 必须明确站上 `close(t1)` 压力位：

```text
1.04 * close(t1) >= close(T) >= 0.98 * close(t1)
```

5. 柱后确认平台不能破坏柱体支撑；当前 `T == t4`，因此没有滞后确认段：

```text
t4+1 ~ T 内，low >= open(t1)
```

6. `T` 日实体涨幅不能过大，避免确认日已经提前消耗次日溢价：

```text
(close(T) - open(T)) / open(T) <= 1.5%
```

## 三、入场、出场

信号出现后观察 `T+1 ~ T+3`，任一观察日记为 `D`。

当 `D` 日开盘价满足：

```text
0.98 * close(t1) <= open(D) <= 1.04 * close(t1)
```

且日内价格冲到：

```text
max(1.005 * close(t1), 1.01 * open(D))
```

时买入。实际买入价不得超过：

```text
min(1.04 * close(T), 横盘最高价 * 1.08, MA10(T) * 1.06, close(t1) * 1.05)
```

买入后只持仓 1 个交易日，按下一交易日开盘价卖出。

仓位使用固定比例定仓，单票买入市值不超过总资产的 `1/4`。
