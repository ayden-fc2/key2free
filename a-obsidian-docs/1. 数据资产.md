# 数据资产

本文档按照当前 DuckDB 命名规范生成，数据库对象分为三层：`source`、`mart`、`meta`。

## 命名规范

| 层级 | 说明 | 命名规则 |
| --- | --- | --- |
| `source` | 外部接口同步后的源数据 | 表名使用业务名，数据来源由 schema 表达 |
| `mart` | 策略和查询可直接使用的计算数据 | 表名使用结果名，计算层级由 schema 表达 |
| `meta` | 数据维护、运行状态和治理元数据 | 表名使用职责名，服务属性由 schema 表达 |
