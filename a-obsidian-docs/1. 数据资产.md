# 数据资产

当前数据资产层已经切换到 `tushare` schema。旧 `source`、`mart`、旧任务表、水位表、校验表和旧维护逻辑已经清理，后续统一围绕 Tushare 接口维护。

## 数据可用范围

当前核心可用区间以 `tushare.bak_basic` 的连续性为准：

- `tushare.bak_basic` 最早有数据日期：`2016-08-09`。
- `tushare.bak_basic` 早期存在不连续缺口，最后一个缺口交易日是 `2016-12-05`。
- `tushare.bak_basic` 从 `2016-12-06` 到当前水位 `2026-06-10` 连续可用。
- `tushare.stock_daily_technical` 作为信号和回测的技术分析中间层，从 `2018-01-01` 起维护，使用 `2017-06-01` 之后的数据作为长窗口指标预热。

因此：

- 数据资产原始层可以追溯到各接口自身水位。
- 需要完整股票基础信息、前复权行情和技术指标的业务逻辑，建议从 `2018-01-01` 之后使用。
- 回测推荐从 2018 年或 2019 年开始。

## 水位表

### `meta.tushare_asset_watermark`

| 字段                   | 类型          | 说明                      |
| -------------------- | ----------- | ----------------------- |
| `asset_table_name`   | `VARCHAR`   | 资产表名，例如 `tushare.daily` |
| `earliest_trusted_watermark` | `DATE` | 最早可信水位，表示该表建议用于业务计算的起点 |
| `trusted_watermark`  | `DATE`      | 最新已处理水位                 |
| `issue_count`        | `BIGINT`    | 刷新中记录的问题次数              |
| `last_issue_at`      | `TIMESTAMP` | 最近一次问题记录时间              |
| `last_issue_scope`   | `VARCHAR`   | 最近一次问题范围，例如交易日或日历窗口     |
| `last_issue_message` | `VARCHAR`   | 最近一次问题说明                |
| `issue_log`          | `VARCHAR`   | 追加式问题日志                 |

`trusted_watermark` 表示“系统已经处理到该日期或窗口”。`earliest_trusted_watermark` 表示业务计算推荐使用的最早日期。若历史缺口已经通过回填或人工处理解决，`issue_count` 会清零，历史处理记录保留在 `issue_log` 中。

如果某次调用返回空、超时或重试耗尽，刷新服务会把问题写入水位表的 issue 字段，并继续推进对应水位，避免一个历史缺口中断整轮更新。

## 刷新规则

- 前端启动刷新时必须传入截止日期 `end_date`。
- 前端默认截止日期规则：本地时间 19:00 前默认昨天，19:00 后默认今天。
- `trade_cal` 按水位到截止日期分年刷新，每轮最多一年。
- `bak_basic`、`adj_factor`、`daily` 根据 `trade_cal.is_open = 1` 的交易日逐日刷新。
- `stock_daily_technical` 是第五步派生资产，依赖 `bak_basic`、`adj_factor`、`daily`，每次维护都按目标水位覆盖式重建完整快照。
- 每次调用 Tushare 接口最多 4 次：首次调用失败后按 10 秒、1 分钟、3 分钟等待重试。
- 单次调用返回空、超时或重试耗尽时，不中断整个刷新任务；服务会记录问题并推进该资产表水位，然后继续后续日期或后续接口。
- `bak_basic` 已确认存在历史缺口，例如个别 2016/2017 交易日会返回 0 行，因此不能用“空结果即任务失败”的硬规则。

### `tushare.stock_daily_technical` 重建规则

目标水位：

```text
target_watermark = min(
  tushare.bak_basic 水位,
  tushare.adj_factor 水位,
  tushare.daily 水位,
  本次刷新 end_date
)
```

`stock_daily_technical` 从 `2018-01-01` 起落表。指标计算会读取 `2017-06-01` 之后的数据作为预热区间，避免 2018 年初的 MA120、ROC120 等长窗口指标全部为空。

每次维护执行覆盖式快照重建：

```text
delete from tushare.stock_daily_technical;
rebuild all rows where trade_date between 2018-01-01 and target_watermark;
update watermark to target_watermark;
```

这样做是因为前复权价格依赖“目标水位下该股票最新复权因子”。当复权因子更新后，历史前复权价格可能变化，不能只增量更新当天。

## 实验性资产（tmp schema）

### `tmp.industry_daily`

行业日频热度聚合表（**实验性**：不在 tushare 刷新流水线内，由 `backend/scripts/build_tmp_industry_daily.py` 基于宽表手工覆盖式重建；验证有效后再正式扩展到 tushare 资产层）。

- 主键 `trade_date + industry`（行业口径 = `bak_basic.industry`，point-in-time）；另含 `industry='__ALL__'` 的全市场聚合行（可作市场广度数据源）。
- 字段：`stock_count`、`avg_pct_chg`、`strong_count/strong_ratio`（行业内 `roc_20>=25%` 个股数/占比）、`limit_up_count`、`amount_sum/amount_share`、`above_ma60_ratio`、`heat_rank`（按 strong_count 排名）。
- 信号层支持：策略在 `required_columns` 声明 `industry_heat_rank` 等行业上下文列（见 `signal_repository.INDUSTRY_CONTEXT_COLUMNS`）时自动按 `trade_date+industry` 联表。
- 注意：宽表刷新后该表不会自动更新，需重跑构建脚本。

## 业务口径

- 股票代码在业务层统一映射为 `sz.000001` / `sh.600000` 形式。
- 前复权日线由 `tushare.daily` 和 `tushare.adj_factor` 现场计算：

```text
qfq_price = raw_price * 当日复权因子 / 目标水位内该股票最新复权因子
```

- 信号、股票上下文图表、回测成交价统一从 `tushare.stock_daily_technical` 读取前复权行情和技术指标。

## 技术指标宽表

### 基础字段

`tushare.stock_daily_technical` 以 `tushare.daily` 为基础，主键口径为 `ts_code + trade_date`，包含：

- 原始行情字段：`open`、`high`、`low`、`close`、`pre_close`、`change`、`pct_chg`、`vol`、`amount`。
- 复权字段：`adj_factor`、`latest_adj_factor`、`qfq_open`、`qfq_high`、`qfq_low`、`qfq_close`、`qfq_pre_close`。
- 股票基础信息：`name`、`industry`、`area`、`pe`、`pb`、股本、资产、利润率、股东人数等 `bak_basic` 字段。
- 状态字段：`is_st`。

### 指标字段

价格波动：

- `atr_5`、`atr_14`、`atr_30`
- `atr_pct_5`、`atr_pct_14`、`atr_pct_30`

成交量：

- `avg_volume_5`、`avg_volume_10`、`avg_volume_20`
- `volume_ratio_5`、`volume_ratio_10`、`volume_ratio_20`
- 成交量字段使用原始 `vol`（手），不做复权折算；`volume_ratio_n = vol / avg_volume_n`，均值窗口包含当日。
- 比例类指标（`atr_pct_*`、`bias_*`、`roc_*`、`ma_slope_*`、`overnight_return` 等）统一为小数，不乘 100。

滚动 VWAP：

- `vwap_5`、`vwap_14`、`vwap_20`、`vwap_30`
- 前复权口径：成交额对复权不变，成交量按 `vol / (adj_factor / latest_adj_factor)` 折算为前复权股数，`vwap_n = sum(amount * 1000) / sum(前复权股数 * 100)`，结果与 `qfq_*` 价格同量纲，可直接与前复权收盘价比较。

均线、乖离和斜率：

- `ma_5`、`ma_10`、`ma_20`、`ma_30`、`ma_60`、`ma_120`
- `bias_5`、`bias_10`、`bias_20`、`bias_30`、`bias_60`、`bias_120`
- `ma_slope_5`、`ma_slope_10`、`ma_slope_20`、`ma_slope_30`、`ma_slope_60`、`ma_slope_120`

趋势效率：

- `er_10`、`er_20`、`er_60`

布林带：

- `boll_upper_10_2`、`boll_middle_10_2`、`boll_lower_10_2`、`boll_bandwidth_10_2`、`boll_percent_b_10_2`
- `boll_upper_20_2`、`boll_middle_20_2`、`boll_lower_20_2`、`boll_bandwidth_20_2`、`boll_percent_b_20_2`
- `boll_upper_60_2`、`boll_middle_60_2`、`boll_lower_60_2`、`boll_bandwidth_60_2`、`boll_percent_b_60_2`

动量：

- `macd_dif_12_26_9`、`macd_dea_12_26_9`、`macd_hist_12_26_9`（`hist = dif - dea`，国际口径，不乘 2）
- `rsi_5`、`rsi_14`、`rsi_20`（简单均值口径 `100 * avg_gain / (avg_gain + avg_loss)`；窗口内无下跌日时为 100，窗口内价格完全无变动时为空）
- `roc_5`、`roc_10`、`roc_20`、`roc_60`、`roc_120`
- `kdj_k_9_3_3`、`kdj_d_9_3_3`、`kdj_j_9_3_3`

K 线结构：

- `body_atr14_ratio`
- `range_atr14_ratio`
- `body_range_ratio`
- `upper_shadow_range_ratio`
- `lower_shadow_range_ratio`
- `overnight_return`

### 口径补充说明

以下口径已通过与独立重算的数值比对验证（误差 < 1e-13）：

- **ATR 平滑方式**：`atr_*` 为真实波幅 TR 的**简单移动平均**（SMA），不是 Wilder RMA 平滑。与通达信/同花顺等行情软件的经典 ATR 数值不同，属于刻意选择的口径。
- **EMA 类指标初始化**：MACD、KDJ 使用递推 EMA，从序列首个有效值起算（KDJ 不做 K=D=50 初始化）。对有半年以上预热数据的股票与经典口径完全收敛；对上市不足约 60 个交易日的新股，早期数值与行情软件存在初始化差异并指数衰减，使用时注意。
- **`is_st` 判定**：基于 `bak_basic` 当日股票名称（含 `st` 字样或以 `*` 开头判 1）。当日 `bak_basic` 缺行时 `name` 为空、`is_st` 记 0，存在少量漏标可能。
- **复权因子缺失日**：`daily` 与 `adj_factor` 按日内连接，某交易日复权因子缺失或非正时该日整行不进宽表（表现等同停牌）。
- **`pct_chg`、`change`**：为 Tushare 原始字段，`pct_chg` 是百分比（已乘 100），与派生指标的"小数"约定不同；除息日 Tushare 基于除权价计算，数值上与前复权口径收益率一致。

## 回测建议

虽然 `trade_cal`、`adj_factor`、`daily` 从 2014 年开始维护，但 `bak_basic` 历史股票列表从 2016 年底开始较稳定，且早期存在少量历史缺口。由于 universe 依赖 `bak_basic`，回测建议从 2018 年或 2019 年开始，避免早期基础列表缺失影响策略覆盖。

## 接口规范

### 交易日历

接口：`trade_cal`

描述：获取各大交易所交易日历数据，默认提取上交所。

积分：需 2000 积分。

输入参数：

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| `exchange` | `str` | N | 交易所：`SSE` 上交所、`SZSE` 深交所、`CFFEX` 中金所、`SHFE` 上期所、`CZCE` 郑商所、`DCE` 大商所、`INE` 上能源 |

| `end_date` | `str` | N | 结束日期，格式 `YYYYMMDD` |
| `is_open` | `str` | N | 是否交易：`0` 休市，`1` 交易 |

输出参数：

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| `exchange` | `str` | Y | 交易所 |
| `cal_date` | `str` | Y | 日历日期 |
| `is_open` | `str` | Y | 是否交易 |
| `pretrade_date` | `str` | Y | 上一个交易日 |
